# Yousif Abdelbagi — personal site

My portfolio site, hosted free on GitHub Pages.

## Add a project
1. Open `index.html` and scroll to `const PROJECTS = [` near the bottom.
2. Copy an existing `{ ... },` block, paste it at the top of the list, and edit the text.
3. Put a photo in the `images/` folder and set `image: "images/your-photo.jpg"` (or leave `image` out).
4. Commit. The site updates in about a minute.

## Things to personalize
- To add LinkedIn, uncomment the LinkedIn line in the contact section and paste your link.
